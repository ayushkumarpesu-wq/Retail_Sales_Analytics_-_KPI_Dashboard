# Cleaned sample data

`retail_sales_sample.csv` is a deterministic random sample of 500 cleaned rows
from the UCI Online Retail dataset (seed 42). It has the same columns as the full
cleaned export, so it can be used to preview the SQL model and dashboard data
shape. Regenerate it with `python src/prepare_data.py`.

Source: Chen, D. (2015). *Online Retail* [Dataset]. UCI Machine Learning
Repository. https://doi.org/10.24432/C5BW33. Licensed under CC BY 4.0.
